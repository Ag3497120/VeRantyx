# Release notes

One file per release, named after its version (`0.1.0-beta.5.md`). `scripts/release.sh` stops without it and puts
it in the appcast, so Glovebox's update window shows it above Install Update.

Write for players who know nothing about how Glovebox works, as Markdown bullets: what they'll notice, most
important first, in plain words, with no version numbers, internal names or detail they don't need. End with how
to update: Check for Updates on the Mac first, then Install Update for the Vision Pro. Get the text approved
before the release.
